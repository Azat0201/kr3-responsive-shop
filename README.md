## Описание и основа проекта
Проект разработан на основе предметной области учебного магазина компьютерной периферии из КР №1 (`kr1-html-css-shop`), дополнен современным интерфейсом и интерактивными сценариями из КР №2, адаптирован без использования Bootstrap (КР №3) и переведён на компонентную архитектуру **React + Vite** со всей JavaScript-логикой и валидацией (КР №4 / КР №5, ПР №12–19).

---

## Практическая работа №12 и №14 (КР №3: Адаптивная вёрстка)
Тема: «Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта».

### Адаптивные решения
- Подключён отдельный файл `src/responsive.css` после базовых стилей;
- Bootstrap **не используется** — вся сетка реализована на CSS Grid и Flexbox;
- Применён подход **Mobile First** с медиазапросами `@media (min-width: 640px / 768px / 1024px)`;
- На всех страницах присутствует корректный `<meta name="viewport" content="width=device-width, initial-scale=1.0">`;
- Реализованы **responsive images**: правило `max-width: 100%; height: auto;`, атрибуты `srcset`, `sizes`, `width`, `height`, `loading="lazy"` в карточках товаров и элемент `<picture>` в Hero-блоке;
- Адаптирована форма заявки (1 колонка на мобильном экране, 2 колонки на планшете и desktop, высота полей `min-height: 44px`);
- Адаптирована таблица характеристик: обёртка `.table-wrapper` + самостоятельная доработка — карточное представление строк таблицы на мобильных экранах (`< 640px`).

### Проверенные ширины в DevTools (без горизонтального скролла)
- `360px` (мобильный экран);
- `430px` (крупный смартфон);
- `768px` (планшет);
- `1024px` (небольшой desktop);
- `1440px` (широкий монитор).

## Практическая работа №13 (A11y-аудит и Lighthouse)
Тема: «A11y-аудит и обеспечение доступности. Использование Lighthouse».

### Исправления доступности
- Добавлена ссылка пропуска навигации `.skip-link` («Перейти к основному содержимому»);
- Настроен чёткий видимый фокус `:focus-visible` (`outline: 3px solid`) на всех интерактивных элементах;
- Проверены осмысленные `alt`-описания у всех 12 товаров;
- Каждое поле формы связано со своим `<label>`, а при ошибках — с текстом ошибки через `aria-invalid="true"` и `aria-describedby`;
- ARIA-атрибуты использованы строго по назначению (`aria-current="page"`, `aria-live="polite"`, `aria-expanded`, `aria-modal="true"`);
- Отчёт аудита сохранён в папке `lighthouse/accessibility-report.html`.

## Практические работы №15, №16, №17, №18 (КР №4: JavaScript и валидация)
Тема: «JavaScript: интерактивность, DOM, события, формы и валидация».

### Реализованный функционал
- **ПР №15 (`src/utils/shopHelpers.js`)**: описаны объекты товаров, использованы `const`/`let`, числа, строки, булевы значения, строгое сравнение `===`. Реализованы функции `formatPrice`, `calculateDiscount`, `calculateFinalPrice`, `getProductStatus`, `createProductSummary`;
- **ПР №16 (`src/data/products.js` и `src/utils/shopHelpers.js`)**: создан массив из 12 товаров с единой структурой. Реализованы функции `getProductTitles`, `getAvailableProducts`, `searchProducts`, `filterProductsByCategory`, `sortProductsByPrice`, `findProductById`, `calculateTotalPrice`, `countAvailableProducts`, `calculateAveragePrice`, `getPreparedProducts`;
- **ПР №17 (`src/utils/validation.js` и `src/App.jsx`)**: реализованы живой поиск, фильтрация по категории, подборке и бюджету, сортировка копии массива `[...products]`, пустое состояние каталога, валидация имени, e-mail и российского телефона (11 цифр с нормализацией `+7`) с выводом ошибок под полями без `alert()`;
- **Принцип безопасного вывода данных**: пользовательские данные, значения полей формы и данные из `localStorage` выводятся исключительно как текст через JSX-экранирование / `textContent` без использования `innerHTML`.

### Самостоятельные доработки
- Полноценная корзина с изменением количества, удалением позиций и расчётом суммы через `reduce`;
- Сохранение корзины, избранного и выбранной темы оформления (`light`/`dark`) в `localStorage`;
- Модальное окно быстрой заявки и интерактивный переключатель карточек всех 12 товаров с таблицами характеристик.

## Практическая работа №19 (КР №5: Компонентная разработка на React + Vite)
Тема: «Старт React-проекта интернет-магазина: Vite, JSX, компоненты и карточки товаров».

- Проект собран на **Vite + React**;
- Интерфейс разбит на функциональные компоненты `Header.jsx`, `ProductCard.jsx`, `ProductList.jsx`, `Footer.jsx`;
- Данные передаются через `props`, списки рендерятся через `.map()` с устойчивым ключом `key={product.id}`.
